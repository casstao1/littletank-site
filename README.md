# LittleTank privacy and support site

This directory contains only the public privacy/support website, not the Swift application.

Publish these files to the root of `casstao1/littletank-site`, then enable GitHub Pages from the `main` branch and `/ (root)`.

- Privacy policy: `https://casstao1.github.io/littletank-site/privacy/`
- Support: `https://casstao1.github.io/littletank-site/support/`

Copy the approved `Nook/Resources/PrivacyPolicy.html` to `privacy/index.html` before publishing. Keep the bundled policy and public policy wording in sync.

The site has no scripts, analytics, third-party fonts, or tracking pixels. GitHub provides hosting and the public support issue tracker under its own privacy terms.
